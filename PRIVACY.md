# Privacy

Mongrel Calculator 0.9.0-beta.1 is an offline utility.

- It contains no analytics, advertising, telemetry, crash-reporting SDK, account system, or network client.
- It reads the pasteboard only when the user invokes **Paste Number**.
- It writes appearance preferences to macOS UserDefaults.
- Calculation history, the memory register, and tab contents remain in memory and are discarded when their window or the app closes.

This statement describes the current source tree. Any future feature that changes the data flow should update this document before release.
